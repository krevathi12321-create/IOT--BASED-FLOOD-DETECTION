# 🌊 IoT-Based Flood Detection and Early Warning System

## 📌 Project Overview

The IoT-Based Flood Detection and Early Warning System is designed to monitor water levels and provide early warnings during potential flood situations.

This project uses ESP32 and IoT technology to continuously monitor water levels and send alerts to users through the Blynk mobile application.

## 🎯 Objectives

- To monitor water levels in real time.
- To detect potential flood conditions.
- To provide early warning alerts.
- To monitor temperature and humidity.
- To enable remote monitoring through a mobile application.

## 🔧 Hardware Components

- ESP32 Development Board
- Water Level Sensor
- DHT11 Temperature and Humidity Sensor
- Green LED
- Yellow LED
- Red LED
- Buzzer
- Breadboard
- Jumper Wires

## 💻 Software and Technologies

- Arduino IDE
- Embedded C/C++
- Blynk IoT Platform
- ESP32 Wi-Fi Connectivity

## ⚙️ Working Principle

1. The water level sensor continuously monitors the water level.
2. The DHT11 sensor measures temperature and humidity.
3. ESP32 processes the sensor readings.
4. Based on predefined thresholds, the system identifies the water level condition.
5. LEDs and buzzer indicate different warning conditions.
6. Sensor readings and flood status are displayed on the Blynk mobile application.
7. Users can remotely monitor the system and receive alerts.

## ✨ Key Features

- Real-time water level monitoring.
- Temperature and humidity monitoring.
- Normal, Warning and Flood Danger indications.
- LED-based visual alerts.
- Buzzer-based audio alerts.
- Remote monitoring using Blynk IoT.
- Mobile alert notifications.

## 🌍 Applications

- Flood-prone areas.
- Water canals.
- Agricultural fields.
- Water storage monitoring.
- Smart environmental monitoring.
